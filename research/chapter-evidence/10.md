# Evidence sheet

## Question

How can a hybrid iOS system diagnose one bounded native/web session without exporting private content, user identifiers, or raw browser traffic?

## Public evidence

- GamePlayer locked at `2e9f314b8f775b2d9564950d1baeb2baa920421b`: pager settle/current-index transitions, primary/inactive cells, navigation-policy decisions, and native loading/error handling.
- `receipe-app` locked at `51d090c26e1b1b7a89d82264938d06a4b047442b`: explicit loading/service-failure state and a basic OSLog-backed logging service.

## Approved generalized MemeArcade evidence

- Native and web lifecycle transitions need a shared, privacy-aware event vocabulary.
- Native code owns bounded session identity, policy, route, and recovery transitions.

No private production log, trace, event schema, vendor, payload, URL, user data, source, metric, or dashboard is approved for publication.

## Claims requiring approval

- Any exact private telemetry behavior, event field, retention policy, security finding, or performance value.

## Planned diagram

Native selection → primary activation → web result/policy decision → native action/recovery → session release, correlated by a short-lived non-user session token.
