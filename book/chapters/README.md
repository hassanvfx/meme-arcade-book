# Chapter map

The editorial chapter map in `plan.html` is authoritative until production evidence requires a correction. Canonical prose belongs in this directory for the print manuscript only; it is not republished as a web course. Draft only after the matching `research/chapter-evidence/<id>.md` documents the public source, production evidence, redactions, diagrams, and claims needing citations. The reader bridge and print QR panels take readers directly to the original public repositories and articles.
